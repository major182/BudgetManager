# プロトタイプ（画面の試作）

[画面設計書](../docs/04_screen-design.md) の見た目と操作の流れを確かめるための試作です。

> **仕様の正ではありません。** 簡略にした部分があります。プロトタイプと画面設計書が食い違ったら、画面設計書が正です（CLAUDE.md 2章）。

## 開き方

`index.html` を Chrome で開くだけで動きます（サーバーは不要）。

### スマホの画面幅で見る

1. Chrome で開き、`F12` で開発者ツールを開く
2. `Ctrl + Shift + M`（デバイスのツールバー）を押す
3. 上部の端末の一覧から「iPhone 12 Pro」などを選ぶ

## プロトタイプでの約束ごと

- **データは画面に直接書いたダミー**です（`js/data.js`）。登録・保存・削除をしても、データは変わりません
- **「今日」は 2026-10-15（木）に固定**しています。明細があるのは 2026年10月だけです
- **ダークテーマが基本**です。設定画面の「テーマ」でライトに切り替えられます
- 実装で htmx とサーバー（Django）が行う処理を、ここでは JavaScript で真似ています。
  特に消費税の計算（`calcTax`）は、実装ではサーバーで行います（技術選定書 5.3）
- Chart.js は `vendor/` に置いたファイルを読み込みます（外部の配信サービスは使わない。技術選定書 7.2 S-03）
