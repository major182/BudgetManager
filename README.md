# 家計簿アプリ（BudgetManager）

## はじめに

- 本リポジトリは、スクールの課題として major182 が作った家計簿の Web アプリ「BudgetManager」に関するものです
- 自分1人で使うための個人版のため、一般の方はご利用いただけません（[利用方法](#利用方法)）

## コンセプト

- 「市販の家計簿アプリは広告や機能が多すぎて続かない」という自分の悩みをもとに、要件定義・設計・実装・テスト・デプロイまでを1人で行いました
- 毎日つけるのが面倒にならないよう、自分が本当に使う機能だけに絞っています

## アプリ概要

- 毎日の収入・支出を記録し、月ごとの収支、分類ごとの使い道、資産の残高を確かめられる家計簿です
- PC とスマホの Chrome で、「家計簿」「統計」「資産」「設定」の4つの画面を切り替えて使います
- 主な機能は次のとおりです
  - 支出・収入・振替の登録（過去の明細からの補完、電卓）
  - 消費税の計算（税込・税抜の入力、8%・10% が混ざる買い物の内訳）
  - 統計（分類ごとの円グラフ、予算の使い具合、12か月の推移）
  - 資産の残高と純資産、クレジットカードの次回の引き落とし額
  - 定期収支の自動登録（給与・家賃・サブスクなど。土日祝日の前後の営業日にずらせる）
  - CSV の出力・取り込み
- Tailscale（VPN）で、本人の端末からしか接続できないようにしています。そのため、ログインの機能はありません
- 使い方の詳細は [操作説明書](docs/07_user-guide.md) をご覧ください

## 環境

- 開発言語：Python 3.14.7
- フレームワーク：Django 5.2.17（LTS）
- 画面：Django テンプレート、htmx 2.0.11、Chart.js 4.5.1
- データベース：MySQL 8.4.11（LTS）
- インフラ：AWS（EC2・RDS・ECR・S3）、Terraform、Tailscale
- CI/CD：GitHub Actions
- 検証済みの環境：Windows 11 Pro の Chrome、Android 17 の Chrome

## 利用方法

- 本アプリは自分1人で使うための個人版で、本人の端末以外からは接続できない構成にしています
- また、課題の終了に伴い AWS の環境は削除しており、現在は公開していません
- そのため、一般の方はご利用いただけません。アプリの動きは [デモ動画](#デモ動画) でご覧ください

## 実装予定の機能

- 入力の手間を減らす機能
  - レシートの写真からの読み取り
  - 銀行・カード会社の利用明細の自動取り込み
- 複数人での共有
  - ログイン機能
  - 家族で1つの家計簿を使い、誰が使ったかを分けて見られる機能
- 外貨への対応
