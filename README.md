# 家計簿アプリ（BudgetManager）

毎日の収入・支出を記録し、月ごとの収支や分類ごとの使い道、資産の残高を確かめるための家計簿です。
PC とスマホの Chrome で使えます。

## デモ動画

https://github.com/user-attachments/assets/8ebd9140-9abe-478e-92bf-598750d2bd64

約3分の動画で、主な操作を次の順に紹介しています。再生できない場合は、[動画のファイル](docs/media/demo.mp4)を開いてください。

| 時間 | 内容 |
|---|---|
| 0:00 | 明細の登録（資産・分類・税率を選び、金額を入れると税額の表が出る） |
| 0:20 | 家計簿の切り替え（日別・カレンダー・月別） |
| 0:30 | 統計（支出・収入の円グラフ、予算の使い具合と超過、消費税） |
| 0:49 | 資産の一覧と推移グラフ（全体・銀行・クレジットカード） |
| 1:15 | クレジットカードの資産詳細（次回の引き落とし） |
| 1:28 | 分類の設定（小分類の追加） |
| 1:47 | 定期収支の登録（周期・土日祝日の扱い・次回の予定日） |
| 2:30 | CSV の出力と、Excel で開いたところ |

※ 表示されている明細・金額は、説明のための架空のデータです。

## はじめに

### 開き方

1. PC・スマホで **Tailscale** のアプリを起動し、接続（オン）にする
2. Chrome で **https://budget.＜tailnet の名前＞.ts.net/** を開く

   ＜tailnet の名前＞は、Tailscale の管理画面の「DNS」に出る `tailxxxx.ts.net` の `tailxxxx` の部分です。一度開いたら、ブックマークしておくと便利です

- 家計簿は、Tailscale に参加している自分の端末からしか開けません。Tailscale がオフだと、ページは表示されません
- ログインはありません。開くと、今月の家計簿が表示されます
- スマホでは、Chrome のメニューの「ホーム画面に追加」で、アプリのように開けます

### 画面の切り替え

画面の下（スマホ）または左（PC）のメニューで、4つの画面を切り替えます。

| メニュー | できること |
|---|---|
| 家計簿 | 日ごとの明細、カレンダー、月ごとの収支を見る。明細を登録・編集する |
| 統計 | 分類ごとの使い道と割合、予算の使い具合、消費税額を見る |
| 資産 | 現金・口座・カードなどの残高と、純資産を見る |
| 設定 | 分類・資産・予算・定期収支などを設定する。CSV で出し入れする |

### 金額の色

金額には「＋」「−」を付けず、色で表します。

| 色 | 意味 |
|---|---|
| 青 | 収入、プラスの残高、返品などで戻ったお金 |
| 赤 | 支出、マイナスの残高（カードの未払いなど）、予算の超過 |
| 灰色 | 振替（自分の資産どうしのお金の移動） |

## 明細をつける

### 登録する

1. 家計簿の画面で、右下の「＋」を押す
2. 上のタブで **支出／収入／振替** を選ぶ
3. 日付・資産・金額・分類などを入れて、「登録」を押す

| 種類 | 使う場面 | 入れるもの |
|---|---|---|
| 支出 | 買い物・支払い | 日付、資産（払ったもの）、内容、分類、税率、金額 |
| 収入 | 給与など | 日付、資産（受け取ったもの）、内容、分類、税率、金額 |
| 振替 | ATM で引き出す、カードの引き落とし、電子マネーへのチャージ | 日付、出金元、入金先、金額 |

便利な機能：

- **内容の補完**：内容を入れ始めると、過去に同じ内容で登録した明細が候補に出ます。選ぶと、分類・資産・金額がまとめて入ります
- **電卓**：金額の欄の横の電卓のボタンで、計算した結果をそのまま金額に入れられます
- **返品・払い戻し**：支出にマイナスの金額（例：-550）を入れると、支出を取り消す明細になります

### 消費税と内訳

- 金額を **税込** と **税抜** のどちらで入れるかを選べます。入れるそばから、税抜額・消費税額・税込額が表示されます
- 分類を選ぶと、その分類の税率（例：食費は 8%）が自動で入ります
- 1回の買い物に、食料品（8%）と日用品（10%）が混ざっているときは「内訳を追加」で行を分けます

### 直す・消す・コピーする

家計簿の明細を押すと、編集の画面が開きます。

- 内容を直して「保存」
- 「削除」で消す（消す前に確認が出ます）
- 「コピー」で、同じ内容の新しい明細を作る（日付は今日になります）

## 家計簿を見る

| タブ | 表示 |
|---|---|
| 日別 | 日ごとの明細と、その日の収入・支出 |
| カレンダー | 月のカレンダーに、日ごとの収入・支出。日を押すと、その日の明細 |
| 月別 | 1年の各月の収入・支出・差額 |

- 上部の「‹」「›」で前後の月（月別は年）へ移ります。「今月に戻る」で今月へ戻ります
- 画面上部に、表示中の期間の収入・支出・合計が出ます。振替は収支に数えません
- 右上の虫めがねで **検索** できます。内容・メモ（一部の文字）、種類、分類、資産、金額の範囲、期間で絞り込めます
- 定期収支で自動で登録された明細には「定期」の印が付きます

## 統計を見る

- **支出／収入** のタブと、**月／年** の切り替えで、分類ごとの金額と割合を円グラフと一覧で表示します
- 分類を押すと、その中の小分類ごとの金額が出ます。「〇〇の推移を見る」で、その分類の過去12か月の棒グラフを見られます
- 月の支出では、**予算** の使い具合（使った額・残り・割合）が出ます。超えた予算は赤で表示されます
- 下の **消費税** の欄で、税率ごとの消費税額の合計がわかります

## 資産を見る

- 資産グループ（現金・銀行・クレジットカード・電子マネー）ごとに、今の残高を表示します。上部に資産・負債・純資産の合計が出ます
- クレジットカードは、未払いの額が負債として赤で出ます。次回の引き落とし日と請求額（締め日の前は「目安」）も表示されます
- 資産を押すと、その資産の月ごとの明細と、明細ごとの残高の動きを見られます
- 右上のグラフのボタンで、資産・負債・純資産の過去12か月の推移を見られます

## 設定

| 項目 | できること |
|---|---|
| 分類 | 支出・収入の分類（大分類・小分類）の追加・名前の変更・並べ替え・非表示。分類ごとの税率 |
| 資産 | 現金・口座・カードなどの追加。開始残高。カードは締め日・引き落とし日・引き落とし口座 |
| 予算 | 全体と大分類ごとの、毎月の予算。特定の月だけ金額を変えることもできます |
| 定期収支 | 給与・家賃・サブスクなど、決まった日に発生するお金の登録（下記） |
| CSV 出力・取り込み | 明細を CSV ファイル（Excel で開けます）に出す・CSV から取り込む（下記） |
| 表示設定 | 通貨記号（¥／円）、桁区切り、月の開始日（給料日に合わせるなど）、週の開始曜日、画面のテーマ（ライト／ダーク）、消費税の端数処理 |
| 税率 | 税率の追加・変更・非表示 |

- 使っている分類・資産・税率は削除できません。使わなくなったものは「非表示」にすると、入力の選択肢に出なくなります

### 定期収支

- 「毎月25日」「毎月末」「毎週月曜」「毎年5月31日」のような周期で、明細を自動で登録します
- 登録日が土日祝日にあたるときに、そのまま／前の営業日／次の営業日のどれにするかを選べます（例：給与は前営業日）
- 一覧に、次に登録される日が表示されます
- 登録を始める日より前の分は、自動では登録されません。必要なら明細として入れてください

### CSV の出し入れ

- **出力**：月または年を選んで「出力」を押すと、その期間の明細を CSV でダウンロードします
- **取り込み**：ファイルを選んで「確認」を押すと、中身を点検します。誤りがあれば、何行目のどこが誤りかが表示され、1件も取り込まれません。誤りがなければ「取り込む」で登録します
- 出力した CSV と同じ見出しの形で取り込めます（1回に 5,000 行・2MB まで）。同じファイルを2回取り込むと、明細も2回登録されます

## 困ったとき

| こんなとき | 確かめること |
|---|---|
| ページが開かない | その端末で Tailscale がオンになっているか。サーバーが止まっていないか（止めている間は開けません） |
| 「Bad Request (400)」と出る | アドレスが「はじめに」の URL（`https://budget.` で始まり `.ts.net/` で終わる）になっているか |
| 端末を失くした | Tailscale の管理画面で、その端末を外す（外すと、その端末からは開けなくなります） |
